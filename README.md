# Scheduler App

The **Scheduler App** is an Android application designed to help users schedule tasks and receive notifications for their planned events. Built with modern Android development tools and best practices, this app ensures a smooth and intuitive user experience.

---

## 🚀 Features

- **Schedule Tasks:** Create, edit, cancel scheduled tasks, and track completed schedules.  
- **Notifications:** Receive timely alerts for scheduled events.  
- **Background Restrictions Handling:** Manages Android 8+ restrictions, notifying users when an app launch is blocked.  
- **Material Design:** A clean and modern UI following Material Design guidelines.  
- **Offline Support:** Tasks are stored locally, ensuring functionality even without an internet connection.  

---

## 🛠️ Tech Stack

The app is built using the following technologies:

- **Kotlin** 
- **Jetpack Compose** 
- **Hilt (Dependency Injection)** 
- **Room (Local Database)** 
- **MVVM Architecture** 
- **Material Theme** 
- **WorkManager (Background Tasks)**
