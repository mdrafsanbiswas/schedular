# Scheduler App

The **Scheduler App** is an Android application designed to help users schedule tasks and receive notifications for their planned events. Built with modern Android development tools and best practices, this app ensures a smooth and intuitive user experience.

---

## Features

- **Schedule Tasks:** Users can create, edit, cancel scheduled tasks and see completed schedules
- **Notifications:** Users receive timely notifications for their scheduled events.
- **Background Restrictions Handling:** Handles Android 8+ background restrictions by notifying users when the app cannot launch directly.
- **Material Design:** A clean and modern UI following Material Design guidelines.
- **Offline Support:** Tasks are stored locally, ensuring functionality even without an internet connection.

---

## Tech Stack

The app is built using the following technologies and tools:

- **Kotlin** 
- **Jetpack Compose** 
- **Hilt** 
- **Room** 
- **MVVM Architecture**
- **Material Theme** 
- **WorkManager**
